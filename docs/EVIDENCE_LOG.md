## Required artifacts per settlement
- Input manifest (redacted, canonical).
- SHA-256 hash.
- Oracle key ID and signature/attestation reference.
- Claim ID.
- Contract ID and version/wasm hash.
- Asset contract address and issuer verification.
- Funding transaction hash.
- Settlement transaction hash.
- RPC readback / event evidence.
- Screenshot or recording of the UI state.
