# Roadmap

## Phase 0 — specification
- Agree on target crop, geography and pilot period.
- Select baseline model with agronomy input.
- Define data schema, units, reward budget and privacy policy.

## Phase 1 — local MVP
- Soroban contract scaffold and unit/integration tests.
- Simulator labeled as simulated.
- Canonical evidence manifest and oracle signer interface.
- Basic web flow and wallet boundary.

## Phase 2 — Stellar Testnet
- Deploy contract.
- Configure test asset.
- Sponsor funds vault.
- Settle a valid claim and verify transaction.
- Demonstrate replay rejection and failure cases.

## Phase 3 — field validation
- Integrate actual sensors/gateway.
- Calibrate and document devices.
- Compare baseline against agronomic protocol.
- Pilot with consent and human review.
- Audit false positives/negatives.

## Phase 4 — production readiness (not committed)
- Independent smart-contract review.
- Independent agronomic methodology review.
- Legal, tax, privacy and stablecoin assessment for Peru.
- Key management, incident response, monitoring and support.
- Mainnet only after all gates pass.
